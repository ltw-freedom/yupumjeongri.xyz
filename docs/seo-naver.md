# 네이버 노출 분석 — 시군구 페이지가 왜 뜨는가

2026-09-24 측정. "송파 유품정리"·"의정부 유품정리" 노출을 계기로 56개 시군구 전체를 재 봤다.
결론: **송파·의정부만의 성과가 아니라 시군구 페이지 템플릿 전체가 네이버에서 먹히고 있다.**
이 문서는 그 순위를 **잃지 않기 위한** 기록이다. 템플릿·URL·도메인을 건드리기 전에 먼저 읽을 것.

## 1. 기준선 (2026-09-24)

네이버 **모바일** 통합검색의 웹 영역, 검색어 "{짧은 이름} 유품정리". 중구·광주는 검색어가 모호해 제외하고 54개.
원본 데이터: [`scripts/data/naver-rank/2026-09-24.json`](../scripts/data/naver-rank/2026-09-24.json)

| 웹 영역 순위 | 개수 | 지역 |
| --- | --- | --- |
| 1위 | 10 | 마포, 은평, 양천, 강서, 구로, 영등포, 서초, 의왕, 하남, 이천 |
| 2위 | 9 | 성동, 중랑, 도봉, 관악, 수원, 안산, 과천, 용인, 화성 |
| 3위 | 7 | 의정부, 노원, 강동, 성남, 부천, 고양, 시흥 |
| 4~9위 | 3 | 양평 4, 송파 5, 파주 9 (칼럼) |
| 12위 밖 | 25 | 종로, 용산, 광진, 동대문, 성북, 강북, 서대문, 금천, 동작, 강남, 안양, 광명, 평택, 동두천, 구리, 남양주, 오산, 군포, 안성, 김포, 양주, 포천, 여주, 연천, 가평 |

- 노출 URL은 파주(칼럼) 하나를 빼면 전부 `/area/{광역}/{시군구}/`. 동 페이지·칼럼은 거의 안 뜬다.
- 네이버는 우리 `<title>`·description 을 그대로 보여준다 — "의정부시 유품정리 · 의정부 유품정리 비용·견적 | 대한유품정리", "의정부유품정리 업체 — …".
- 12위 밖 25곳도 **색인은 되어 있다**. "종로구유품정리 대한유품정리"처럼 상호를 붙이면 나오고, 강북·광명·평택 등은 웹 탭 2페이지(16~30위)에 있다.

## 2. 원인

근거 강도를 같이 적는다. "강함"은 데이터로 확인, "중간"은 상관관계, "추정"은 정황.

**① 검색어에 정확히 맞춘 시군구 템플릿 — 강함, 가장 큰 요인**
[`src/pages/area/[region]/[city]/index.astro`](../src/pages/area/[region]/[city]/index.astro) 의 `title`·`description`:

- title 에 붙여쓰기 "의정부시유품정리"와 [`cityShortName()`](../src/data/areas.ts) 의 "의정부 유품정리"를 **둘 다** 넣는다. 네이버 검색은 접미사 없이, 붙여서 하는 경우가 많다.
- description 이 "의정부유품정리 **업체**"로 시작한다 (2026-08-11 `a9f5e00`).
- H1·URL·BreadcrumbList 가 같은 키워드로 정렬돼 있다.

상위 12개 경쟁자도 거의 전부 같은 형태의 지역 랜딩 페이지(olbaruncare, gajogae, allbarunclean …)다.
이 검색어의 웹 영역은 "지역 페이지끼리의 경쟁"이고, 우리 페이지는 그 형식에 정확히 맞는다.

**② 손으로 쓴 지역 콘텐츠는 결정 요인이 아니다 — 강함**
의정부는 생성 티어다 — 큐레이션 특징·칼럼·사례·웨이브1 동 페이지가 전부 없는데 3위.
은평·구로·의왕·이천도 생성 티어로 1위. 반대로 큐레이션 + 칼럼 3편이 걸린 강남은 12위 밖.
순위를 만드는 건 템플릿 구조와 사이트 공통 신호이고, 큐레이션은 보조다.

**③ 색인 기반 — 강함**
서치어드바이저 등록·사이트맵(2026-08-11, 시군구 56개 전부 포함), IndexNow(2026-09-07, [`scripts/indexnow.mjs`](../scripts/indexnow.mjs)).
시군구 페이지는 색인이 병목이 아니다 (1장 마지막 항목).

**④ 시군구 페이지로 모이는 내부 링크 — 중간**
홈 → 56개 시군구 전부 링크, [`adjacency.ts`](../src/data/adjacency.ts) 실제 생활권 인접 링크(의정부 ↔ 노원·도봉·양주),
동 페이지 1,000여 개 → 상위 시군구. 전부 2026-09-13 `b6b0107` 기준.

**⑤ 현장 사진은 클릭률 보조 — 추정**
2026-09-03 에 넣은 사례 사진이 검색 결과 썸네일로 뜬다. 그런데 1위인 마포·서초에는 썸네일이 없다 —
사진 추가 전 수집본으로 이미 1위였다는 뜻으로 읽힌다. 순위의 뿌리는 8/11 구조다.

**⑥ 노출·미노출을 가르는 건 키워드별 경쟁 — 중간**
12위 밖 키워드에는 `jongno.yoopoom.com`·`gangnam.yoopoom.com`·`namyangju.olbaruncare.com` 처럼
**그 지역 전용 서브도메인** 경쟁자가 상위에 있는 경우가 많다 (yoopoom 서브도메인 등장 비율: 미노출 24% vs 1~3위 4%).
송파도 `songpa.yoopoom.com` 이 1위, 우리는 5위.

## 3. 측정 한계

- 모바일만. PC 검색(search.naver.com)은 스크립트 요청을 차단한다.
- 비로그인, 측정 PC 의 IP 위치 기준 (2026-09-24 측정은 미국 IP). 절대 순위보다 **같은 방식으로 잰 이전 측정과의 변화**를 볼 것.
- 과거 데이터가 없어 **언제부터** 올랐는지는 모른다 — 서치어드바이저 검색 유입, 네이버 애널리틱스(2026-09-07 설치)에서 볼 것.
- AI 브리핑 인용: 2026-09-24 엔 확인되지 않았으나, **2026-10-06 운영자가 '의정부 유품정리' AI 브리핑에 우리 사이트가 노출되는 것을 확인**했다.
  같은 날 의정부 시군구 페이지는 웹 영역 12위 밖(10/2 3위 → 제목 검색에도 안 나옴)이었다 — AI 브리핑은 웹 영역 순위와 따로 움직인다.
  AI 브리핑 내용은 페이지 로드 뒤 스크립트로 채워져 `naver-rank.mjs` 같은 HTML 수집으로는 보이지 않는다. 확인은 실제 화면으로.
  인용될 만한 직답 문장(`priceAnswer()`)·가격표·FAQ 는 시군구 본문 축소(4-2) 때도 남겼다. 이것들을 빼지 말 것.

## 4. 유지 규칙

**하지 말 것**

- 시군구 페이지 `title`·`description` 패턴과 `cityShortName()` 변경. 가장 직접적인 순위 요인이다.
  고쳐야 한다면 몇 개 지역에만 먼저 적용하고 순위를 재서 확인한 뒤 넓힐 것.
- URL 구조·slug 변경, trailing slash 정책 변경.
- `.xyz` → `.co.kr` 도메인 이전. 쌓인 신호가 초기화될 위험 — 2026-10-06 운영자 결정으로 이전하지 않는다.
- 동 페이지 사이트맵 전량 투입 (`astro.config.mjs` 의 `SITEMAP_DONG_WAVE = 'all'`). 네이버 색인률 12% 상태에서는 저품질 신호가 된다.
- `BaseLayout` 의 `naver-site-verification` 메타 삭제.

**할 것**

- 템플릿을 고친 뒤, 그리고 주기적으로 순위를 재서 기준선과 비교 — 아래 5장.
- 12위 밖 지역 중 검색량이 큰 곳(강남·남양주·김포·안양)부터 지역 칼럼·실제 사례 보강.

## 4-1. 변경 이력 — 순위와 비교할 것

- **2026-09-24 전환 개선.** 시군구·동 템플릿의 title·description·H1·URL·`cityShortName()` 은 그대로 두고
  **본문만** 바꿨다: H1·lead 아래 가격 요약 + 번호 칸(`AreaQuick`), 비용 H2 첫 문장을 직답 문장(`priceAnswer()`)으로,
  가격표 아래 예상 비용 계산기(`EstimateCalc`), 하단 CTA 에 번호 칸. 배포 후 1~2주 안에 `naver-rank.mjs` 로
  재측정해 기준선(2026-09-24)과 비교할 것. 떨어진 지역이 몰리면 이 변경부터 의심한다.

- **2026-10-27 description 가격 파일럿 (시군구 5곳).** 가평·고양·군포·의정부·성북만 description 첫머리에 '원룸 40만원부터(부가세 별도)'. 4-9 참고.

## 4-2. 2026-10-06 하락 — 시군구 페이지가 유사문서로 묶였다

**측정.** 12위 안 29개(9/24) → 39개(10/2) → **18개(10/6)**. 1위가 됐던 마포·양천·강서·과천·하남·은평 등 26곳이 12위 밖.
원본: [`2026-10-06.json`](../scripts/data/naver-rank/2026-10-06.json).

**원인 — 경쟁이 아니라 제외.** 근거 강도 순:

- **강함** — 떨어진 페이지는 **자기 title 을 그대로 검색해도 안 나온다** (`"마포구유품정리 · 마포 유품정리 비용·견적"` → 우리 결과 없음).
  같은 방식으로 지금 순위에 있는 용산·관악은 1위로 나온다. 순위가 밀린 게 아니라 네이버가 결과에서 뺀 것.
  (`site:` 검색은 지금 순위에 있는 페이지도 빠뜨려서 판단 근거로 못 쓴다.)
- **강함** — 시군구 페이지끼리 본문이 **평균 77% 같았다** (5단어 shingle Jaccard, 지역명을 지운 뒤, 본문 `<main>` 기준).
  같은 검색어 1위를 가져간 galmuricare 의 지역 페이지끼리는 24~30%.
- **중간** — 용산은 10/2 에 없다가 10/6 에 1위로 돌아왔다. 페이지가 들어갔다 빠졌다 하는 건 유사문서 묶음에서
  대표 문서를 바꿔 고르는 모양과 맞는다.
- **추정** — 9/24 변경(4-1)이 시군구 페이지에 같은 블록(가격 요약·계산기)을 더해 겹침을 키웠고, 재수집 뒤 반영됐다.

**조치 (2026-10-06).** title·description·H1·URL 은 그대로, 본문의 공통 블록만 줄였다:
'왜 대한유품정리인가' 비교표·진행 과정 5단계·서비스 카드 설명·가격표 아래 중복 고지 → 링크로.
생성 티어 FAQ 를 지역 고유 사실(법정동 이름·일반구·인접 시군구·신도시 별칭)로 다시 씀 (`cityFaqs()`).
결과: 평균 유사도 **0.77 → 0.65**, 평균 본문 1,026 → 719 단어. 남은 공통분은 가격표·계산기(전환 요소라 유지).

**다음.** 1~2주 뒤 재측정. 그래도 안 돌아오면 남은 수단은 **지역마다 실제로 다른 본문**을 늘리는 것뿐이다 —
지어낸 지역 정보는 금지이므로 공공 통계(시군구별 주택 종류·1인 가구 등) 같은 출처 있는 숫자가 후보.
**시군구 페이지에 공통 블록을 다시 늘리지 말 것** (템플릿 주석에도 적어 둠).

**"유품정리 비용" (지역 없는 검색어).** 웹 영역이 3칸뿐이고 나머지는 블로그. 상위는 가격표가 아니라
"업체 고르는 기준"류 안내 글이다. `/cost/` 에 '견적서 비교할 때 확인할 5가지' 섹션과 FAQ 1개를 더했다.
